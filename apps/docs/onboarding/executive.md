# Executive Onboarding

This guide is for leaders and decision-makers who need to understand Aigency's purpose, structure, and strategic direction without deep technical implementation details.

## What Aigency Is

Aigency is a **multi-agent AI operating system**. It coordinates 10 executive AI agents — each with a distinct role, identity, and expertise — around a shared memory layer and 3D spatial interface.

Think of it as a **digital executive team** where each agent specializes in a function (engineering, marketing, finance, etc.) and collaborates through structured memory and identity documents.

## Key Differentiators

1. **Agent-native architecture** — The system is designed *for* agents, not merely *with* them
2. **TELOS identity framework** — Every agent has a structured purpose document (mission, goals, risks)
3. **Local-first inference** — Runs on local hardware (M1 Pro, Intel nodes) rather than cloud APIs
4. **On-chain quality gates** — Smart contracts verify knowledge vault health before minting credentials

## Quality Metrics

The `HarvestMoon.sol` contract enforces vault quality:

| Metric | Threshold | Why It Matters |
|--------|-----------|---------------|
| Health Score | >= 85/100 | Ensures agent identity docs are complete |
| Wiki Density | >= 70% | Raw notes are being compiled into knowledge |
| Vault Age | >= 90 days | Prevents premature credential minting |

## Governance

- **THE_ARCHITECT** (human) approves all agent TELOS changes
- **ZENITH** orchestrates squad priorities
- All agent code changes are version-controlled in git
- Agent TELOS edits require PR approval (planned)

## Investment Thesis

Aigency represents a bet that **agent identity and memory** will be as important as agent capability. In a world with many capable AI systems, the ones with coherent identity, persistent memory, and structured purpose will outperform.
