## Mission

The Landing Page Squad owns the end-to-end landing page generation pipeline for Aigency products. From discovery through production-ready implementation, this squad handles all aspects of high-converting landing page creation.

---

## Squad Members

| Agent | Role |
|-------|------|
| Landing Page Discovery Specialist | Uncovers conversion requirements and user goals |
| Market Research Specialist | Competitive and market analysis |
| Landing Page Strategy Director | Converts research into strategy blueprints |
| Design System Architect | Design token and component system generation |
| Landing Page Copy Optimizer | Section-by-section copy engineering |
| Landing Page Architect | Production-ready implementation |

---

## Workflow

```
Discovery Specialist  -->  Requirements + user goals
        |
Market Research       -->  Competitive analysis + positioning
        |
Strategy Director     -->  Blueprint + conversion strategy
        |
Design System Arch    -->  Tokens + components
        |
Copy Optimizer        -->  Section copy + CTAs
        |
LP Architect          -->  Production implementation
```

---

## Outputs

- Conversion requirements document
- Competitive analysis report
- Landing page strategy blueprint
- Design token system
- Component library
- Production-ready landing page code
