## Mission

The Agile Squad handles product management, architecture blueprints, research, and agile ceremonies for the Aigency platform. It complements the Meta Code Squad by owning "what to build" while Meta Code Squad owns "how to build it."

## Relationship to Meta Code Squad

```
Agile Squad (owns WHAT)
    |-- PRDs --> Meta Code Squad implements
    |-- Architecture --> Meta Code Squad builds
    |-- Research --> Informs Meta Code Squad decisions
    |-- Backlog --> Meta Code Squad executes

Meta Code Squad (owns HOW)
    |-- Implementation --> Agile Squad reviews
    |-- Quality gates --> Agile Squad accepts
    |-- Technical decisions --> Logged to ledger
```
