# @aigency/agent-core

> Shared agent types, interfaces, and constants for all Aigency agents.

## Overview

Central type definitions used across the monorepo:

- Agent callsigns and metadata
- Directive, pattern, and timeline types
- Message and event formats

## Usage

```typescript
import type { AgentCallsign, DirectiveRecord } from "@aigency/agent-core";
```

## Commands

```bash
pnpm test          # run tests
pnpm test:coverage # run tests with coverage
pnpm typecheck     # TypeScript check
pnpm build         # build with tsup
```
